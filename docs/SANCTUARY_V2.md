# THANDU — Live Memory Sanctuary V2

**State:** Code committed to `main`, Vercel deployment READY. This is a **public-safe design preview**, not the photo-bearing birthday release.

## What changed from V1

- New celestial atrium composition with an independent aurora, beams, architecture, lanterns, responsive petals, reflective floor and steps.
- A more readable central scene hierarchy: chapter title and short instructions above five individually identified memory portals.
- Five differently arranged, individually animated memory objects with visible names and numbers; no portal depends on a hidden click hotspot.
- Discovery progress from zero to five.
- A larger memory viewer with distinct photo-stage architecture, previous/next navigation and dedicated close action.
- Keyboard Escape and basic dialog focus cycling; proper button labels and `aria-pressed` discovery state.
- Pointer parallax on independently rendered environment elements; reduced-motion option retained.
- The original photograph rendering contract remains `object-fit: contain` at natural aspect ratio. No facial/identity editing operations are implemented.

## Public preview limitations

- Memory portals contain **art-only placeholders**. There are **no real photographs** in the public GitHub repo, published JS, assets, or Vercel site.
- Some architectural geometry is CSS/SVG-like 2.5D, not a fully modeled three-dimensional scene.
- The live preview does not yet match the final illustrated keyframes, does not include a complete life timeline, and lacks the final birthday celebration and personal letter.
- The code passed syntax and structural checks; Vercel reported a READY deployment. **Full live-browser screenshot / mobile device / performance / accessibility QA is not yet complete for this V2.** These checks remain required before declaring the scene finished.
