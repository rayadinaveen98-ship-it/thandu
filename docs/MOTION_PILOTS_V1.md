# THANDU — Living Worlds Motion Pilots V1

**Status:** Working browser-tested prototype; creative acceptance pending. No personal photos, video, private media manifest or private messages included.

## Production results

### Pilot A — The Arrival
- Guiding light follows an animated path toward the celestial gateway over approximately 7.4 seconds.
- Independent particle trail, touch ripples, ambient motes, shimmering water effects and gateway pulses.
- 2.5D approach uses a real animated scaling and motion transform over one original matte painting. **It is not a navigable 3D environment.**
- Intentionally separate Start / Skip / Replay and Garden navigation controls. Tapping scenery creates light instead of navigating.

### Pilot B — A World in Bloom
- Five independently authored SVG blossom objects, with separately transforming petals and stamen.
- Each bud is a real button, with visual focus, keyboard activation and aria-pressed state.
- Each flower triggers independent petals, ripples and a bloom counter; vines and garden effects activate as discoveries accumulate.
- This is genuine independent on-page geometry/animation, **not the background garden painting becoming physically animated**.

## Shared engineering
- Self-contained offline HTML output with two original people-free artwork assets embedded, no remote fonts/assets.
- Touch and mouse interactions, keyboard-accessible bloom controls, sound-free prototype, browser motion toggle, reduced-motion preference, replay, explicit navigation.
- No original photos of the birthday recipient were viewed by or fed into generative art in these pilots; none were copied into the working HTML.
- Photo identity policy applies to future scenes: [IDENTITY_PRESERVATION.md](IDENTITY_PRESERVATION.md).

## Quality checks

Tested headless Chromium with mobile 390×844 and desktop 1440×900 layouts:
- Opening, travel start, skip, return, chapter switching, all five blossom clicks, completion, motion toggle and replay.
- No JavaScript page errors detected; no document-level horizontal overflow at tested sizes.
- Screenshots inspected and desktop side framing adjusted in second pass.
- **Not yet physically tested on recipient's specific handset** or fully performance-profiled on low-end devices.
